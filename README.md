# 🏠 AI Virtual Family House

Create virtual family members for emotional companionship. Built for lonely people and hostellers.

## ✨ Features

- Create family members (mom, dad, sister, brother, grandparent)
- Customize appearance + religion
- AI-powered conversations with persistent memory (Mem0)
- Festival celebrations based on religion
- TraumaDump mode for emotional release with calm monk/sage

## 🛠️ Tech Stack

- **Frontend**: Next.js + React + Tailwind CSS
- **Database**: Supabase (PostgreSQL)
- **AI**: Gemini 2.5 Pro (free 1M tokens) + Ollama (local fallback)
- **Memory**: Mem0 (persistent conversation memory, 51K GitHub stars)
- **Deployment**: Hugging Face Spaces (free CPU)

## 🚀 Quick Start

```bash
npm install
cp .env.example .env
# Add your API keys to .env
npm run dev
```
